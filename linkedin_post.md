# 🚀 StreamFlow: Your Ultimate Personal Dashboard

Excited to share my latest personal project, **StreamFlow**! 🎥✨

I built this all-in-one dashboard to merge entertainment and productivity into a single, seamless web experience. Whether you want to catch up on live TV, listen to global radio, or get deep work done with a focus timer—it's all here in one crisp interface.

### ✨ Key Features:
📺 **Live TV Streaming:** Smooth playback powered by HLS.js.
🌍 **Global Chat:** Real-time, instant messaging using **MQTT over WebSockets**.
🎵 **Music & Radio:** Integrated audio player with access to stations worldwide.
📰 **Smart News:** Aggregated top headlines to keep you informed.
🧠 **Focus Mode:** Built-in Pomodoro timer & ambient noise (White/Brown noise) for peak productivity.
☀️ **Live Weather:** Real-time forecasts and updates.

### 🛠️ Tech Stack:
*   **Core:** HTML5, CSS3, Vanilla JavaScript
*   **Streaming:** HLS.js for HTTP Live Streaming
*   **Real-time:** MQTT.js for the chat infrastructure
*   **APIs:** Open-Meteo, News API, Radio-Browser
*   **Security:** Implemented strict Content Security Policy (CSP) & reliable fallback strategies.

I focused heavily on creating a **premium, responsive UI** that feels as good to use as it looks.
